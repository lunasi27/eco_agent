**架构优化附注**（开发过程中迭代引入的设计改进）：
- **Gate 节点**：phase2_gate / phase3_gate 解决 Send 并行 + 多目标条件边的 race condition
- **Error Handler 路由下沉**：节点内部 Command(goto) 替代调用层 update_state + Command(goto)，绕开 checkpoint metadata 残留
- **方案 A：全阻断错误语义**：Phase2 任意并行 Step error 都进 error_handler（原设计 run_sta=阻断、PV/Signoff=警告），原型阶段安全性优先
- **agent_entry 为正式入口**：意图识别从 Init 中分离为独立前置节点
- **Phase2 Send 用共享字段白名单**：避免并行节点互相覆盖独立写入的字段
- **参数化构图（pipeline dict）**：build_graph(pipeline=) 接收配置动态注册节点/边，Gate/Route/Summary 全工厂函数化闭包捕获参数，运行时图拓扑固定（无"注册了但不走"的假节点），Phase2/Phase3 step 可裁剪，Phase3 可跳过或硬路由，config_loader 构图前校验
